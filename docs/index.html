Playable Packer

Drop one Luna export and get a build for each network: the CTA and end-of-game calls rewired to that network's API, packed as the HTML or ZIP it accepts, sized against its cap and scanned for outside requests. Files never leave this page.

What changes in each build
  • A small bridge script goes first in <head>. It routes the CTA (mraid.open, FbPlayableAd.onCTAClick, ExitApi.exit, window.install, playableSDK.openAppStore, store links opened with window.open) to the target network's call, and stands in for the other networks' objects so the export never touches an API that is not there.
  • End of game: when the game calls window.__playableGameEnd() (or mraid.close() / gameEnd() on networks that stand them in), the bridge maps it to gameEnd() (Mintegral) or postMessage("complete") (Liftoff).
  • MRAID networks get <script src="mraid.js">; Google gets its ExitApi script and ad.orientation meta; other builds lose any network script tag the export carried.
  • Check CTA loads the bridge in a sandboxed frame with that network's API stubbed and reports which call fired. Still run each file through the network's own preview or validator before a campaign.
